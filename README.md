# Sovereign's Umbriel Config

My personal Umbriel configuration files!

This setup includes Umbriel configs for keybindings, window rules, animations, noctalia v5. Intended for a dual montior setup.

## Install
> [!CAUTION]
> Take a backup of your existing config first, this will override whatever you have!

```bash
git clone https://github.com/ViSovereign/umbriel-configs.git
cd umbriel-config
```
